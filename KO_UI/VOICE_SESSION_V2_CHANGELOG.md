# KO Voice Session V2

## 변경 내용

- 호출어 `웨이크 업 케이오`를 한 번 감지하면 기본 30초 동안 연속 음성 명령을 받습니다.
- 명령이 들어올 때마다 음성 세션 시간이 다시 30초로 연장됩니다.
- 리치 측정 화면에서는 최대 5분 동안 호출어 없이 측정 명령을 이어서 사용할 수 있습니다.
- 훈련 준비 화면에서는 3분, 실제 훈련 중에는 훈련 시간에 맞춰 음성 세션을 유지합니다.
- 훈련을 터치로 시작해도 훈련 중 `일시정지`, `계속해`, `현재 기록`, `훈련 종료`, `비상정지` 명령을 바로 사용할 수 있습니다.
- `대화 종료`, `음성 종료`, `음성 대기 모드로 돌아가` 명령으로 즉시 호출어 대기 상태로 복귀합니다.
- 음성 합성 안내가 다시 명령으로 잘못 인식되지 않도록 청취 억제 시간을 유지합니다.
- 시스템 설정의 상태 카드를 더 작게 만들고 기술 명칭 및 운영 설명을 사용자용 표현으로 정리했습니다.

## 기본 음성 흐름

```text
웨이크 업 케이오
→ 음성 대화 시작
→ 새 사용자 등록
→ 이름은 정우
→ 키는 175센티
→ 오른손잡이야
→ 저장하고 측정
→ 리치 측정 시작
```

각 단계에서 호출어를 다시 말하지 않아도 됩니다. 일반 화면에서는 30초 동안 말이 없으면 자동으로 호출어 대기 상태로 돌아갑니다.

## 환경 변수

필요할 때만 `.env`에서 조정합니다.

```bash
VOICE_SESSION_TIMEOUT_SEC=30
VOICE_SESSION_MAX_SEC=3600
VOICE_SESSION_FOLLOWUP_DELAY_SEC=0.8
VOICE_SESSION_VOICE_HITS=2
```
