# KO Sporty Red UI 변경사항

- 메인 화면을 매트 블랙·복싱 레드 기반의 스포츠 대시보드로 전면 개편
- 좌측 고정 메뉴 추가: 홈, 훈련, 분석 리포트, 기록 관리, 프로그램, 사용자 관리, 시스템 설정
- 기존 로봇 복싱 사진을 메인 히어로 영역에 배치하고 어두운 그라데이션으로 배경과 결합
- 메인 화면의 카메라·마이크·로봇·비전·OpenAI·SQLite 연결 카드를 제거
- 장치 및 서비스 상태를 새 `시스템 설정` 화면으로 이동
- 최근 사용자와 최근 훈련 지표, 사용자 등록/불러오기 기능 유지
- Wake Word 하단 도크를 레드 네온 스타일로 변경하고 STT 명령 예시 추가
- 기존 SQLite, Wake Word, Whisper STT, ROS 2 브리지, 위빙 로봇 노드, 선택형 비전 실행 구조 보존
- 모바일에서는 좌측 메뉴가 하단 내비게이션으로 전환
